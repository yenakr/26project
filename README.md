# 🏃‍♂️🏃‍♀️ 이런저런 러닝크루 자동 출석 관리 웹 서비스

카카오톡 대화록(`.txt`) 파일을 자동 분석하여 월별/인원별 러닝 참석 일수를 카운트하고, 학기별 회원 등급(신입/정회원/OB) 및 회원유지 조건 충족 여부를 관리하는 웹 대시보드 애플리케이션입니다.

---

## 🔒 1. 깃허브(GitHub) & Vercel 보안 및 개인정보 처리 방안

> [!IMPORTANT]
> **대화록 및 개인정보 미포함 원칙 (Client-Side Parsing)**
>
> 1. **대화록 미Commit 규칙**: `.gitignore`에 `*.txt`, `*.xlsx`, `*.csv` 규칙이 적용되어 있어 크루 대화록이 GitHub에 업로드되는 것을 근본적으로 차단합니다.
> 2. **100% 브라우저 메모리 파싱**: 대화록 파일 업로드 시 서버로 전송되지 않고 사용자의 웹 브라우저 메모리 상에서만 즉시 연산됩니다.
> 3. **PIN 접속 제한**: 접속 시 비밀번호 `0214`를 입력해야만 출석부에 접근 가능합니다.

### 🚀 Vercel 1분 무료 배포 방법 (Private Repository)
1. **GitHub**에서 새 저장소를 만들 때 **Private(비공개)**로 생성 후 코드를 push합니다.
   ```bash
   git init
   git add .
   git commit -m "feat: 러닝크루 출석체크 웹 대시보드 구축"
   git branch -M main
   git remote add origin https://github.com/사용자이름/26project.git
   git push -u origin main
   ```
2. [Vercel.com](https://vercel.com)에 로그인 후 **New Project** -> Private 저장소를 연결하고 **Deploy** 버튼을 클릭합니다.
3. 배포된 URL을 크루원 및 운영진과 공유하여 사용합니다.

## 📋 2. 주요 기능

- 🔑 **PIN 게이트 접속 통제**: 비밀번호 `0214`
- 💬 **카카오톡 대화록 `.txt` 자동 파서**:
  - `@이름` 태그 기반 참석 인원 추출
  - 모임 종류(정규런, 템포런, 번개런, 대러리, 레드불, 춘천, YTN 등) 감지
  - 날짜별 `12(대러리)`, `5(레드불)` 형태 자동 포맷팅
  - `~님이 들어왔습니다.` 로그 기반 신규 입부 일시 감지
- 📊 **공지 엑셀 이미지 양식 100% 매칭**:
  - **이름**, **학기 수**, **월별 출석(26.9, 26.10, 26.11, 26.12)**, **합계**, **유지 조건**, **비활동 여부(군 휴학/비활동)**, **보증금/비고**
  - **등급별 행 배경색**: 🟩 신입회원(초록), 🟦 정회원(파랑), 🟥 OB 회원(분홍)
- 🎯 **회원유지 조건 자동 판정**:
  - **신입 / 정회원**: 학기당 **4회 이상** 참석 🟢
  - **OB 회원 (3학기 이상)**: 학기당 **2회 이상** 참석 🟢
- 📥 **공지용 엑셀(xlsx) 내보내기**: 클릭 한 번으로 단톡방 공지용 엑셀 다운로드
- 💾 **JSON 백업 & 복원**: 관리자 간 전체 출석부 데이터 백업/복원
